# CAD 제조 Feature 추출 기준 예시

> 시제품 RAG 검증용 초안입니다. 실제 도면 레이어·블록·치수·공차·재질 표기 규칙으로 교체해야 합니다.

## 추출 대상

- 제품군과 도면 개정번호
- 길이, 폭, 높이, 두께와 재질
- 원형 홀·슬롯의 종류, 수량, 크기와 간격
- 절곡·성형·절단에 영향을 주는 형상
- 추출 방법, 항목별 신뢰도와 예외 사유

CAD Parsing 결과와 YOLOv8·OCR 결과가 다르면 자동 확정하지 않는다. 도면 원본과 개정번호를 확인하고 설계 또는 견적 담당자가 제조 Feature를 승인한다.
