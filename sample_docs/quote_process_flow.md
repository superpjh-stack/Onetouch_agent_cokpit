# 원터치 CAD 견적 표준 흐름 예시

> 문서번호 OT-KB-007 / 개정 R0 / 담당 영업·견적 / 상태 샘플·미승인

견적은 접수, 도면 버전 확인, CAD 객체 추출, 제조 Feature 검토, BOM·공정 Routing 생성, 표준원가 비교, 승인 순서로 진행한다.

신뢰도와 예외가 표시되어도 자동 고객발송은 하지 않는다. 도면 예외, 소재 부족, 원가 근거 누락이 있으면 해당 담당자가 확인한 뒤 견적 책임자가 최종 승인한다.

DB 연결 예시: QT-260904-001, QT-260904-002, QT-260904-003
