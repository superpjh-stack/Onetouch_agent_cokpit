# CAD 견적 모델 검증 가이드 예시

> KPI 수치는 사업 목표이며 현재 달성값이 아닙니다.

- CAD 객체 인식률 목표: 90% 이상
- 견적 오차 목표: 실제 제조원가 대비 ±5% 이내
- 견적 리드타임 목표: 기존 대비 80% 이상 단축
- 견적 근거 추적성 목표: 100%

시간순 홀드아웃으로 학습·검증 데이터를 분리하고 제품군, 재질, 두께와 도면 품질별 성능을 따로 측정한다. SHAP 등으로 주요 원가 기여요인을 표시하고, 드리프트 또는 원가 기준 변경 시 모델을 재검증한다. 기존 승인 모델로 롤백할 수 있어야 한다.
