# 도면 개정·변경관리 절차 예시

> 문서번호 OT-KB-005 / 개정 R0 / 담당 설계 / 상태 샘플·미승인

견적 접수 시 파일명, 도면번호, 개정번호를 확인한다. 새 개정이 접수되면 기존 CAD 추출값과 BOM·공정·원가 후보를 자동 확정하지 않고 변경 항목을 비교한다.

개정번호가 없거나 서로 다르면 설계 담당자가 최신 원본을 확인할 때까지 견적을 보류한다. 승인 후 변경된 제조 Feature부터 다시 계산하고 이전 결과와 변경 사유를 함께 남긴다.

DB 연결 예시: DWG-260904-003, QT-260904-003
